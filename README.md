# زخرفة أسماء — موقع متعدد الصفحات

موقع أدوات (Tool Website) كامل بـ HTML وCSS وجافاسكربت خالصة — بدون أطر عمل أو مكتبات أو باك-إند. **57 صفحة** تشمل مولدات زخرفة عاملة فعلياً ومحتوى SEO عربي أصلي.

## الأدوات العاملة

- **مولد الزخرفة**: 27 نمطاً (خطوط يونيكود لاتينية + تطويل/تشكيل/تأطير عربي)، نتائج حية، نسخ فوري، فلاتر
- **محوّل الخطوط**: صفحة مستقلة لكل خط بمحوّل حي
- **مولد أسماء المستخدمين**: اقتراحات ذكية من كلمة الأساس
- **مكتبة الرموز / الإيموجي**: نسخ بضغطة واحدة
- **الأحرف المخفية**: نسخ حروف لا تُرى
- **تصاميم الأسماء الجاهزة**: 8 قوالب Canvas أصلية — اكتب اسمك مرة واحدة فيظهر فوراً على كل التصاميم، مع تحميل PNG
- **مجموعات جاهزة**: قوائم أسماء بنسخ فوري

## كيف تُبنى الصفحات (المولد)

الصفحات تُولَّد محلياً بسكربت Node ثم تُنشر كـ HTML ثابت — **لا يوجد build على Vercel**:

```
_generator/
├── site.js      # الإعدادات والقوائم (الألعاب، المنصات، الخطوط)
├── h.js         # دوال بناء HTML
├── tpl.js       # قالب الصفحة الموحد (SEO + هيدر + فوتر)
├── p-games.js   # محتوى صفحات الألعاب (12)
├── p-social.js  # محتوى صفحات التواصل (10)
├── p-fonts.js   # محتوى صفحات الخطوط (11)
├── p-misc.js    # المراكز والأدوات والمجموعات والمدونة والثابتة
└── build.js     # سكربت التوليد
```

لإعادة البناء بعد تعديل المحتوى:

```bash
cd _generator && node build.js
```

ثم ارفع الملفات الناتجة. (يمكنك أيضاً تعديل أي `index.html` مباشرة.)

## المعاينة محلياً

```bash
cd zakhrafa-names
python3 -m http.server 8000
# http://localhost:8000
```

## النشر على Vercel

1. ارفع المشروع إلى GitHub.
2. في Vercel: **Add New → Project** ← استورد المستودع.
3. **Framework Preset:** `Other` — **Build Command:** فارغ — **Output Directory:** فارغ.
4. **Deploy**.

## ⚠️ قبل النشر

1. استبدل `https://www.example.com` بدومينك الحقيقي (ابحث في كل الملفات).
2. ضع بريدك الحقيقي بدل `hello@example.com` في `_generator/p-misc.js` (صفحة اتصل بنا) وأعد تشغيل المولد.

## SEO

- عناوين ووصف meta فريدة لكل صفحة، canonical، Open Graph
- بيانات منظمة: WebPage + BreadcrumbList في كل صفحة، وFAQPage حيث توجد أسئلة
- `sitemap.xml` يُولَّد تلقائياً بكل الصفحات، و`robots.txt` جاهز
- روابط داخلية: مسار تنقل (breadcrumb) + بطاقات صفحات ذات صلة + روابط سياقية
- كثافة الكلمة المفتاحية «زخرفة اسماء» في الرئيسية: **0.64%**
